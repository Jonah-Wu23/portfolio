01 / NAVIGATION BUDDY · PRODUCT JUDGMENT SEC 02 // 03

从「最快路线」到「懂我的路线」

产品判断 导航 Agent 原型 · 效用模型与软约束决策落地
01 · 效用 ≠ ETA 感知代价折算
排序看感知代价。耗时之外计算耗时波动、转向次数、信号灯与过路费，统一折算为等价分钟进行路径评估。
02 · 偏好是软约束 阈值即额度
「晚 5 分钟」即为阈值额度。绕开代价 ≤ 阈值就执行绕行；超出额度时不硬绕并明确说明原因，支持一键提额。
03 · 记忆可见可控可溯源可删 透明控制台
每条偏好带原话、时间、来源场景、置信度与应用次数；阈值支持拖动微调，可随时暂停、删除或查看流水。
04 · 解释先于惊喜 额度尺审计
改推前先展示解析卡片，改推时给出新旧方案对比、额度尺消耗、逐维度折算明细与被否决方案的理由。

PROJECT 02 // 留乘智行 · 需求响应公交智能调度系统 [40.7831° N, 73.9712° W]

路网建模与寻路机制重构 OSM Graph Topology & Edge-level Cost Evaluation

01 / 三层图拓扑建模 OSM 拓扑
构建站点层、物理路网层与动态需求拓扑层的三层图结构。包含 558 个核心站点与 16,740 条拓扑边，承接纽约曼哈顿 270 万条真实出行订单，全域需求可达率达到 99.88%。
02 / 边级综合代价评估 代价重构
寻路机制跳出离散单步选点逻辑，重构为评估候选路径的综合代价。将乘客绕行时间代价与潜在流失风险显式编码为边特征，边级 Q 值网络直接输出下一跳路径决策。
03 / 强化学习与连续约束 连续惩罚项
基于时空图神经网络聚合路网动态，将车辆额定容量与乘客最长容忍等待等硬约束改写为可微连续惩罚项，保障高并发下的求解稳定性与平滑收敛。
决策视角：从离散选点重构为候选路径边级代价评估，与导航 Agent 的偏好效用折算及软约束求解一脉相承。
