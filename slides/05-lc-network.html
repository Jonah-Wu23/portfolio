PROJECT 02 // 留乘智行 · 需求响应公交智能调度系统 [40.7831° N, 73.9712° W]

路网建模与寻路机制重构 OSM Graph Topology & Edge-level Cost Evaluation

01 / 三层图拓扑建模 OSM 拓扑
我用 OSM 数据搭建了三层图：物理路网、路由图、调度图，一共 558 个核心站点、16,740 条边。把纽约曼哈顿 270 万条真实订单放上去跑，99.88% 的需求都接得住。
02 / 边级综合代价评估 代价重构
常规调度每一步只需要选择下一个节点，我把决策改成评估整条候选路的综合代价：绕行代价和流失风险都编码成边特征，由边级 Q 值输出下一跳。
03 / 强化学习与连续约束 连续惩罚项
时空图神经网络负责聚合路网动态；车辆容量、乘客最长等待这些硬约束，我改写成连续惩罚项放进目标函数，高并发下训练依然稳定收敛。
从「选择下一个节点」到「评估每条候选路」，这个决策视角和导航 Agent 给路线排序是一脉相承的。
